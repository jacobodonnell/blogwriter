# Git Commits

## Commit Frequently

- Commit after each logical unit of work - don't wait until the end of a feature
- Each commit should represent a single, coherent change

## Format

```
<type>: <description>
```

**Types:** `feat:`, `test:`, `fix:`, `refactor:`, `style:`, `build:`, `docs:`, `Agent:`

**Examples:**
```
feat: add Articles navigation item
test: fix Article tests and factory
fix: home layout dashboard link button
refactor: remove ArticleSeeder.php
build: install alpine and alpine-ajax
Agent: make advisor-mode a skill
```

## Style

- Use imperative mood ("add" not "added")
- Keep concise but descriptive
- No ending period
